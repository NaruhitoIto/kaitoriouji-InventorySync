出荷データ作成（ShippingExport.exe）の使い方
==========================================

ワサビスイッチの代わりに、各モールの「出荷できる注文」から出荷システム用の注文CSV
（order-YYYYMMDDHHMMSS.csv。ワサビと同じ65列）を作ります。

■ 毎日の作業
 1. ファイルをダウンロードする
    - 出荷済みリスト: ピッキングリスト作成の end-order（「ピッキングリスト作成 - end-order.csv」）
      ← これに載っている注文番号は出力しません（前回までに出荷した注文）
    - 楽天   : 不要（アプリが API で「発送待ち」の注文を取ります）
    - Amazon : セラーセントラルの注文レポート（2日前くらいから）
    - メルカリ: ショップ管理画面の注文CSV（orders_….csv）
    - ヤフオク: 注文CSV（YahooAuctionId, OrderId, Title … の列があるファイル）。入金済みだけ出力します
 2. ShippingExport.exe をダブルクリックする
 3. 「注文日がこの日時以降」はそのままでよい（初期値は14日前。出荷済みリストで除外するので広めにしています）
 4. 「注文ファイルを追加…」で 1 のファイルをすべて選ぶ（まとめて選べます。種類は自動で判定し、一覧に [出荷済みリスト] [Amazon] などと出ます）
 5. 「出荷データを作成」を押す
    → 「出荷データ」フォルダに order-….csv ができるので、出荷システムに取り込む
 6. 警告が出たら確認する（下記）

■ 同じ商品の重複注文（在庫連携の漏れで二重に売れたもの）
 - 同じ商品コードが複数の注文に入っていると、警告の画面が出ます
 - 先に注文された方を「発送」、後から注文された方を「キャンセル候補」とします
   （同じ時刻なら Amazon → 楽天 → メルカリ → ヤフオク の順で発送を優先）
 - キャンセル候補の注文は出荷データに入れず、「重複注文_要確認_….csv」に出します。
   モールでキャンセルするか、発送するモールを変えるかを決めてください
   （キャンセル候補の方を発送する場合は、その注文を出荷システムに手で入れてください）
 - 一覧は「重複SKU_アラート_….csv」にも出ます
 - 前回までに出荷データに出した商品が、また別の注文で売れていた場合も「キャンセル候補」になります

■ そのほかの画面のメッセージ
 - Amazon のキャンセル・発送済み・保留中の注文 … API で確認して出力しません
 - ヤフオクの未入金の注文 … 出力しません（入金後にもう一度）
 - メルカリでお届け先の住所が無い注文 … 出力しません（手作業で確認）
 - 商品コードが無い明細 … 出力はしますが、商品コードが空なので手作業で確認
 - 「出荷済みリストが追加されていません」… end-order を追加し忘れています。二重出荷に注意

■ 二重出荷を防ぐしくみ
 - 出荷済みリストにある注文番号は出力しません
 - アプリで一度出力した注文は「出力履歴.json」に記録し、次からは出力しません（このファイルは消さないでください）
 - 同じ注文をもう一度出したいときは「出力済みの注文は除く」のチェックを外します

■ 別のPCで使う
 - このフォルダ（ShippingExport.exe・shipping_export.ini・出力履歴.json）をそのままコピーします。Python は不要です
 - shipping_export.ini に API のキーを入れ、config_file は空にします（キーはチャットやメールに貼らないでください）
   [RAKUTEN_API]   service_secret / license_key
   [AMAZON_SP_API] client_id / client_secret / refresh_token（キャンセル確認用。空なら確認しません）
 - 2台で同時に使うと出力履歴が別々になります。作業は1台で行うか、出力履歴.json を最新のものに入れ替えてください
 - 初めて開くと Windows の警告（SmartScreen）が出ることがあります。「詳細情報」→「実行」で開けます

■ 設定（shipping_export.ini）
 - モール名（楽天市場店・Amazon店・メルカリ・ヤフオク店）、ステータス（本日発送分）、配送業者（日本郵便）、
   出力先フォルダ、ヤフオク店の注文番号の頭（vivoage-）、注文日の初期値（14日前）を変えられます
