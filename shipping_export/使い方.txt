出荷データ作成（ShippingExport.exe）の使い方
==========================================

ワサビスイッチの代わりに、各モールの「出荷できる注文」から出荷システム用の注文CSV
（order-YYYYMMDDHHMMSS.csv。ワサビと同じ65列）を作ります。

■ 毎日の作業
 1. ファイルをダウンロードする
    - 出荷済みリスト: ピッキングリスト作成の end-order（「ピッキングリスト作成 - end-order.csv」）
      ← これに載っている注文番号は出力しません（前回までに出荷した注文）
    - 楽天   : 不要（アプリが API で「発送待ち」の注文を取ります）
    - Amazon : セラーセントラルの注文レポート（2日前くらいから）
    - メルカリ: ショップ管理画面の注文CSV（orders_….csv）
    - ヤフオク店・ヤフーショッピング店: ストアクリエイターProの注文CSV（YahooAuctionId, OrderId, Title … の列がある
      download.csv）。入金済みだけ出力します。オークションIDが無い注文はヤフーショッピング店として出力します
      ＋ 同じ期間の注文データの明細ファイル（default_all_items.csv）も一緒に追加してください
        （ショッピングの注文は download.csv に商品コードが無いため、明細の「Product Code」から補います。
          default_all_orders.csv は追加しても使いません）
    - ヤフオク1（個人アカウント）: ファイルは不要（4-2 で取引ナビを貼り付けます）
 2. ShippingExport.exe をダブルクリックする
 3. 「注文日がこの日時以降」はそのままでよい（初期値は14日前。出荷済みリストで除外するので広めにしています）
 4. 「注文ファイルを追加…」で 1 のファイルをすべて選ぶ（まとめて選べます。種類は自動で判定し、一覧に [出荷済みリスト] [Amazon] などと出ます）
 4-2. ヤフオク1 の注文は、1件ずつ次をくり返す
    - ブラウザで取引ナビ（「商品を発送してください」の画面）を開く
    - Ctrl+A（すべて選択）→ Ctrl+C（コピー）
    - アプリの「取引ナビを貼り付け」を押す → 一覧に [ヤフオク1 取引ナビ] オークションID・商品コード・商品名 が出る
    ※ 氏名・住所・配送方法の送料・落札価格・数量・商品コード・終了日時・オークションIDを読み取ります
      （注文番号＝オークションID、受注日・入金日＝終了日時、合計＝落札価格×数量＋送料）
    ※ 「発送連絡をする」がある取引（入金済み・未発送）だけ受け付けます。未入金・発送連絡済みはエラーになります
    ※ お届け先が出ていない取引（匿名配送など）や、商品コードが「（商品コードなし）」と出たものは手作業で確認してください
    ※ 取引ナビの文字をテキストファイルに保存したものは「注文ファイルを追加…」でも読み込めます
    ※ 貼り付けた注文は「注文日がこの日時以降」より前でも出力します
 5. 「出荷データを作成」を押す
    → 「出荷データ」フォルダに order-….csv ができるので、出荷システムに取り込む
 6. 警告が出たら確認する（下記）

■ ヤフオク店の売上明細（商品番号ごと）
 1. ストアクリエイターProから、必要な期間の次のファイルをダウンロードする
    - 注文データの明細（default_all_items.csv）と注文（default_all_orders.csv）
    - 注文CSV（download.csv）… 入金状況と、1つ目の商品の商品コードを読むため（無くても作れます）
 2. 「注文ファイルを追加…」で上のファイルを追加し、「売上明細（ヤフオク店）」を押す
 3. 「出荷データ」フォルダに2つのCSVができる（Excel でそのまま開けます）
    - 売上明細_ヤフオク店_….csv … 1行＝1商品（注文日時・注文番号・明細番号・オークションID・商品番号・商品名・数量・
      単価・小計・送料・値引き・ポイント・注文合計・支払方法・入金状況・商品番号の取得元）
      送料・値引き・ポイント・注文合計は注文の1行目にだけ入ります（合計で二重に数えないため）
    - 売上集計_ヤフオク店_….csv … 商品番号ごとの明細数・数量合計・売上合計・最初と最後の注文日時・注文番号
 ※ ファイルに入っている注文をすべて対象にします（期間はダウンロードするときに指定してください）
 ※ ヤフーショッピングの注文と、キャンセルされた注文は入りません
 ※ 商品番号は「商品名の中の商品番号」→「注文CSVの商品コード」→「ワサビの商品名で検索」の順で探し、
   分からないものは「（商品番号不明）」にまとめます
   ワサビの検索は商品名を50件ずつまとめて行います（1000注文で1分ほど。ログに「検索中（ヤフー｜商品名 50/474）」のように
   進み具合が出ます）
 ※ 出荷済みリストや出力履歴は使いません。何度作っても同じ内容になります

■ 発送日ごとの売上集計（楽天・Amazon）
 1. 「売上集計（楽天・Amazon）の発送日」に期間を入れる（初期値は今月1日〜昨日）
 2. 「売上集計（楽天・Amazon）」を押す（ファイルの追加は不要。API で取得します）
 3. 「出荷データ」フォルダに 売上集計_発送日_….csv ができる（Excel でそのまま開けます）
    1行＝1日。楽天・Amazon・合計それぞれの 売上金額・売上点数・売上件数 と、最後の行に期間の合計
 ※ 売上金額は 商品代金＋送料（税込）。楽天は「商品合計＋送料」、Amazon は商品代金・送料・ギフト包装と税の合計から
   割引を引いた額（注文合計と同じ）。ポイント利用分は引きません。返金・返品も引きません
 ※ 発送日: 楽天は RMS の「発送日」。Amazon は出荷を確定した日時（財務データに売上が計上された日時）
 ※ 楽天のキャンセルされた注文は入りません
 ※ Amazon は呼び出し回数の制限があり、1日分に30秒ほど（1か月分で15分ほど）かかります。ログに進み具合が出ます
 ※ メルカリ・ヤフーなどは、API で連携できるようになるまで集計しません
 ※ shipping_export.ini の [RAKUTEN_API] と [AMAZON_SP_API] のキーが必要です

■ 同じ商品の重複注文（在庫連携の漏れで二重に売れたもの）
 - 同じ商品コードが複数の注文に入っていると、警告の画面が出ます
 - 先に注文された方を「発送」、後から注文された方を「キャンセル候補」とします
   （同じ時刻なら Amazon → 楽天 → メルカリ → ヤフオク → ヤフオク1 の順で発送を優先）
 - キャンセル候補の注文は出荷データに入れず、「重複注文_要確認_….csv」に出します。
   モールでキャンセルするか、発送するモールを変えるかを決めてください
   （キャンセル候補の方を発送する場合は、その注文を出荷システムに手で入れてください）
 - 一覧は「重複SKU_アラート_….csv」にも出ます
 - 前回までに出荷データに出した商品が、また別の注文で売れていた場合も「キャンセル候補」になります

■ そのほかの画面のメッセージ
 - Amazon のキャンセル・発送済み・保留中の注文 … API で確認して出力しません
 - ヤフオクの未入金の注文 … 出力しません（入金後にもう一度）
 - メルカリでお届け先の住所が無い注文 … 出力しません（手作業で確認）
 - 商品コードが無い明細 … 出力はしますが、商品コードが空なので手作業で確認
   ヤフオク店のまとめて取引は、注文CSVに2つ目以降の商品コードがありません。タイトルに商品番号があればそれを使い、
   無ければワサビスイッチの商品名（ヤフー｜商品名・表示用商品名）から探します（[WASABI] の設定が必要）。
   同じ商品名の商品が複数あるときは決められないので、ログに「候補: 商品番号 / 商品番号」と出ます。どちらか確認してください
   ※ ヤフオク店の商品ファイル（NE_Items.csv・syouhin.csv）には商品コードが無いので、追加しなくてよい
 - 「出荷済みリストが追加されていません」… end-order を追加し忘れています。二重出荷に注意

■ 二重出荷を防ぐしくみ
 - 出荷済みリストにある注文番号は出力しません
 - アプリで一度出力した注文は「出力履歴.json」に記録し、次からは出力しません（このファイルは消さないでください）
 - 同じ注文をもう一度出したいときは「出力済みの注文は除く」のチェックを外します

■ 別のPCで使う
 - このフォルダ（ShippingExport.exe・shipping_export.ini・出力履歴.json）をそのままコピーします。Python は不要です
 - shipping_export.ini に API のキーを入れ、config_file は空にします（キーはチャットやメールに貼らないでください）
   [RAKUTEN_API]   service_secret / license_key
   [AMAZON_SP_API] client_id / client_secret / refresh_token（キャンセル確認用。空なら確認しません）
   [WASABI]        token（wasabi_config.ini と同じ KEY:SECRET。ヤフオクの商品コード探し用。空なら探しません）
                   InventorySync があるPCなら token は空のまま config_file = C:\InventorySync\wasabi_config.ini でも可
 - 前からある shipping_export.ini には [WASABI] がありません。末尾に次の2行を書き足してください
     [WASABI]
     token = （wasabi_config.ini の token と同じもの）
 - 2台で同時に使うと出力履歴が別々になります。作業は1台で行うか、出力履歴.json を最新のものに入れ替えてください
 - 初めて開くと Windows の警告（SmartScreen）が出ることがあります。「詳細情報」→「実行」で開けます

■ 設定（shipping_export.ini）
 - モール名（楽天市場店・Amazon店・メルカリ・ヤフオク店・ヤフオク1）、ステータス（本日発送分）、配送業者（日本郵便）、
   出力先フォルダ、ヤフオク店の注文番号の頭（vivoage-）、注文日の初期値（14日前）を変えられます
